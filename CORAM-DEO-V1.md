# CORAM DEO — V1

## Objetivo

Construir e lançar rapidamente a primeira versão oficial do Coram Deo,
com uma experiência simples, elegante e funcional, deixando recursos
avançados para atualizações futuras.

## Funcionalidades do V1

### Experiência do aluno
- Dashboard
- Biblioteca
- Devocionais
- Assistente Coram Deo
- Calendário de estudo
- Conta do aluno
- Notificações
- Onboarding
- Pesquisa global
- Favoritos
- Anotações
- Planos de leitura
- Planos e preços

### Administração
- CMS de conteúdos
- CMS de usuários
- Gestão de planos e preços
- Gestão de notificações

## Fora do V1

- Escola Teológica
- Cursos
- Sistema geral de progresso
- Gamificação
- Certificados
- Comunidade
- Métricas administrativas avançadas
- Recursos sociais avançados

## Princípios

1. V1 simples, funcional e elegante.
2. Arquitetura preparada para crescer.
3. Não construir funcionalidades sem necessidade.
4. Não misturar o V1 com o beta antigo.
5. Identidade visual consistente em todas as telas.
6. Mobile-first.
7. Segurança desde a fundação.

## Identidade

O Coram Deo deve transmitir:

- profundidade
- reverência
- excelência
- clareza
- modernidade
- acolhimento

O produto não deve parecer um aplicativo religioso genérico.
